# HANOI-HUST-SCGP

Reproducible code and audit artifacts for the Sealed Compound Generalization Protocol (SCGP) study in bearing-fault diagnosis.

## Contents

- `manuscript.tex`, `manuscript.pdf`: Applied Sciences submission version.
- `scripts/`: figure-generation scripts used in the manuscript.
- `artifacts/`: public registries, audit summaries, and preregistration materials.
- `docs/`: study documentation.

## Reproducibility

The repository contains derived audit materials and scripts. Original HANOI HUST and external raw datasets are not redistributed. Dataset access, licensing, and file-level restrictions are documented in the manuscript and registry files.

The main manuscript can be compiled with the MDPI class and standard LaTeX tools. Exact split manifests, prediction arrays, and environment details are provided in the accompanying submission package where redistribution is permitted.
