# HANOI-HUST-SCGP

Manuscript source, derived evidence, and reconstruction code for the Sealed Compound Generalization Protocol (SCGP) study in rotating-machinery fault diagnosis.

Current reproducibility release: **2.1.0 (2026-08-02)**. The canonical public repository is <https://github.com/niubisile-wq/HANOI-HUST-SCGP>. A version-specific Zenodo DOI can be added after this GitHub release is archived.

## Evidence boundary

SCGP is a prospective evaluation contract. The empirical tracks are reported at the strongest level supported by their retained access history:

- HANOI HUST G2 is the primary crossed partition--aggregation audit.
- The HANOI compound track is a historical held-out confirmation under a documented local freeze, not a publicly time-stamped prospective lockbox.
- The initial Paderborn result is a one-shot three-code external pilot.
- A disjoint 12-code Paderborn extension was registered before numeric access and scored without external tuning; it is reported separately from the pilot and historical unscored 15-code registry.
- G3, NOACE, calibration, perturbation, and efficiency results are secondary audits.

## Contents

- `manuscript.tex`, `manuscript.pdf`: Machines submission manuscript.
- `supplementary_information.tex`, `supplementary_information.pdf`: supporting information.
- `Definitions/`, `figures/`, and the table `.tex` files: complete LaTeX dependencies.
- `scripts/` and `source_data/`: figure builders and CSV source data for the primary Figures 2--3 and legacy Supplementary Figures S1--S2.
- `src/`: builders, evaluation scripts, and reconstruction audits.
- `tests/`: unit tests for the HANOI HUST implementation.
- `artifacts/hanoi_hust/`: derived source and confirmation feature caches.
- `results/g2/`: primary split manifests, record predictions, bearing predictions, and endpoint summaries.
- `results/g3/`: secondary model-family and Paderborn boundary results.
- `results/analysis/`, `results/confirmation/`, and `results/development/`: retained legacy and boundary outputs.
- `artifacts/paderborn_three_code_boundary_registry.json`: registry for the initial three-code pilot.
- `artifacts/paderborn_twelve_code_extension_registry.json`: pre-access-frozen registry for the disjoint 12-code extension; `artifacts/paderborn_confirmatory_registry.json` remains the separate historical unscored 15-code registry.
- `research/`: access contracts, evidence timeline, registry files, and audit reports. The dated G0 artifact manifest preserves historical pre-release hashes; use `src/audit_repository_cross_hashes.py` for the active public-release references.
- `CITATION.cff`, `.zenodo.json`, and `RELEASE_NOTES.md`: versioned citation and Zenodo-deposit metadata.

Raw HANOI HUST and Paderborn waveform archives are not redistributed. The repository contains only manuscript-specific derived features, predictions, split manifests, summaries, and provenance records. High-resolution TIFF figures are regenerated by the plotting scripts and are excluded from Git history to keep the archive compact.

## Environment

Python 3.12 was used for the release audit. Install the packages required for the primary audits, tests, and figures with:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
```

The secondary MiniROCKET and neural-network scripts additionally require `requirements-optional.txt`.

## Compile the manuscript

The repository contains the MDPI class files required for standalone compilation with pdfTeX.

```powershell
latexmk -pdf -interaction=nonstopmode -halt-on-error manuscript.tex
pdflatex -interaction=nonstopmode -halt-on-error supplementary_information.tex
pdflatex -interaction=nonstopmode -halt-on-error supplementary_information.tex
```

## Reconstruct the primary audit

The main reconstruction entry points are:

```powershell
python src/audit_hanoi_hust_g2_main_table.py
python src/analyze_hanoi_hust_g2_protocol.py
python src/audit_paderborn_twelve_code_extension.py
python src/audit_repository_cross_hashes.py
python -m pytest -q
```

The primary manuscript numbers can also be checked directly against `results/g2/factorial_endpoint_metrics.json` and the three corresponding record-prediction arrays in `results/g2/unit_level_predictions/`.

All manuscript figures can be regenerated with:

```powershell
python scripts/make_figure2_primary_g2.py
python scripts/make_figure2.py
python scripts/make_figure3.py
python scripts/make_figure4.py
```
